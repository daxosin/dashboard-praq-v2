# Matrice reglementaire par domaine -- Pharma78

Reference : Bible GOV-QMS-002 §6.1
Usage : verifier que chaque SOP cite les referentiels obligatoires selon son domaine.

## Lecture

- **OUI** = reference obligatoire dans la section 3 de la SOP
- **--** = non applicable pour ce domaine
- **COND** = conditionnel (obligatoire si la SOP traite de ce sujet)
